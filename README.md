# 🎮☢️ Radio4Fun  
### Simuladores & Jogos Educativos em Radiologia e Física

Radio4Fun é uma plataforma educacional interativa desenvolvida para o ensino de **Física Radiológica**, utilizando **simuladores e jogos digitais** como ferramenta de aprendizagem.

O projeto combina conceitos acadêmicos com uma abordagem lúdica, promovendo aprendizado ativo, visual e prático.

---

## 🚀 Objetivo

Transformar conteúdos complexos da radiologia em experiências interativas, facilitando o entendimento de temas como:

- ⚡ Física das radiações
- 🖥️ Processamento de imagens
- ☢️ Radioproteção
- 🌀 Tomografia Computadorizada
- 📺 Fluoroscopia
